# Full Stack Developer Portfolio

Static portfolio built with HTML, CSS, JavaScript and Bootstrap 5.

## Run
Open `index.html` in a browser (needs internet for the Bootstrap CDN), or serve it:

    npx serve .

## Customize
- Name, bio, experience: edit `index.html`
- Projects: edit the `projects` array at the top of `js/main.js`
- Colors: edit the CSS variables at the top of `css/style.css`
- Contact form: currently front-end only. Point it at your own API in `js/main.js` (see the comment in the submit handler).

## Deploy free
Drag the folder onto Netlify Drop, or push to GitHub and enable GitHub Pages.
